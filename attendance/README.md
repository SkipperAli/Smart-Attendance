# attendance/

Attendance records are written here, one CSV per day:

```
attendance/2026-10-01.csv
```

```csv
name,time,distance
Sara Khan,08:52:10,0.2013
Ali Abbas,09:01:44,0.1741
```

`distance` is how far the face was from the closest enrolled photo (lower = more certain).

Everything in this folder except this README is git-ignored.
